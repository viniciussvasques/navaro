## 🌐 App Web Estabelecimento (DUNNAA Pro Web)

> Versão web do app para estabelecimentos. Mesmas funcionalidades do App Barbeiro (mobile), acessíveis pelo navegador para uso em desktop/tablet.

### Escopo
- Todas as features do **App Barbeiro (DUNNAA Pro)** (B01–B121) disponíveis na interface web.
- Foco em uso em computador/tablet na barbearia (agenda, fila, check-in, financeiro, etc.).
- Autenticação e permissões alinhadas ao app mobile (mesma API e roles).

### Diferenciais Web
| Aspecto | Descrição |
|---------|-----------|
| **Uso** | Gestão do estabelecimento no navegador, sem instalar app no PC |
| **Responsivo** | Layout adaptado para desktop e tablet |
| **Stack** | Next.js (consistente com Admin) |

## � Fluxos Importantes

### Fluxo: Avaliação → Google
```
1. Cliente finaliza atendimento
2. App pede avaliação (1-5 ⭐)
3. Cliente escreve comentário
4. Cliente escolhe profissional favorito (opcional)
5. Cliente pode dar gorjeta (opcional)
6. Avaliação salva no sistema
7. Barbearia vê avaliação
8. Barbearia aprova para Google
9. Sistema envia para Google Places API
```

### Fluxo: Modo Fila
```
1. Cliente chega na barbearia
2. Abre app → "Entrar na fila"
3. Sistema mostra posição (3º da fila)
4. Barbeiro "Próximo!"
5. Cliente recebe notificação
6. Cliente é atendido
```

### Fluxo: Gorjeta
```
1. Atendimento finalizado
2. Cliente avalia
3. Opção "Dar gorjeta ao profissional"
4. Valores: R$5, R$10, R$20 ou personalizado
5. Pagamento via Stripe
6. 100% vai pro profissional (sem taxa)
7. Profissional vê no app
```
