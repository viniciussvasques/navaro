# Brand Guidelines - Dunnaa

## 🎨 Color Palette: "Deep Ocean"
**Philosophy:** Trust, Professionalism, Cleanliness.

| Color Name | Hex Code | Usage |
| :--- | :--- | :--- |
| **Primary** | `#005F73` | Main buttons, active tabs, key headers. (Deep Teal) |
| **Secondary** | `#0A9396` | Secondary actions, illustrations. (Tiffany Blue) |
| **Accent** | `#E9D8A6` | Highlights, special offers, distinct badges. (Champagne) |
| **Surface** | `#FFFFFF` | Backgrounds, cards. |
| **Text Main** | `#1A1A1A` | Primary text. |
| **Text Muted** | `#64748B` | Secondary text, placeholders. |
| **Success** | `#94D2BD` | Success states, availability. |
| **Error** | `#AE2012` | Error states, dangerous actions. |

## 🖌️ Logo: "The Monogram" (Concept A)
**Concept:** A stylized, fluid letter **"D"**.
-   **Dunnaa (Customer):** minimalist "D".
-   **Dunnaa Pro:** "D" with a star/badge accent.

## 📱 Typography
-   **Font Family:** `Plus Jakarta Sans` (to be installed).
-   **Headings:** Bold, colored in Primary or Dark Grey.
-   **Body:** Regular, legible.

## 🧩 UI/UX Style
-   **Rounded Corners:** `rounded-2xl` (approx 16-20px) for cards.
-   **Shadows:** Soft, diffused shadows (`shadow-sm`, `shadow-md`).
-   **Glassmorphism:** Occasional use on overlays or bottom tabs.
